# Henrey Hu - Portfolio

Plain HTML/CSS/JS, no build step.
The home page and both project case study pages (`projects/stretch.html`, `projects/wave-maze.html`) live in this repo.

Each case study links out to its own deep write-up repo for the real code and the full technical breakdown, https://github.com/HenreyHu/stretch-writeup for STRETCH and https://github.com/HenreyHu/waves-writeup for WAVES.
A separate plain-markdown index repo lists every project in one place for anyone browsing GitHub directly rather than the site, https://github.com/HenreyHu/Portfolio.

## Notes

- Dark/light theme follows the visitor's system preference and can be toggled with the button top-right.
  The choice is not saved between visits by design (no localStorage).
- The "Systems & Demos" and "Data & ML" sections are intentionally empty/planned stub cards.
- Case study pages are narrative only, no code snippets. Code lives in the write-up repos linked above.
